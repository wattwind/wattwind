Set up your fan

Once: choose your own password for the fan's Wi-Fi network (instead of the default wattwind, which anyone can look up) and a PIN for its settings. The fan buttons keep working without the PIN, and this device remembers it.
Moving from another fan? Settings → Maintenance → Restore from a file brings its settings over instead.

Maintenance

Backup

Save the settings as a file (riders, thresholds, sensors, timing, Wi-Fi name) and restore them on this fan or another one, for example after swapping the Pico. Passwords and keys only if you tick the box.

Firmware update

Pick a wattwind-update-….tar file. The fan turns off while the files come in, checks every file, then restarts with the new version (about a minute; usually only a few files change). Your settings stay. Check for updates asks GitHub from this phone or computer (not from the fan) whether there is a newer version.

Detailed recording

For finding a problem: for 24 h the fan records every second what it gets (power, cadence, heart rate) and what it does, plus its connections, in a file of its own. Start it, ride until the problem shows, then download it and send it with your report. It stops by itself after 24 h and is deleted 7 days later (or with Delete). It holds your heart rate: share it only with someone you trust.
No recording.

Restart

Erase everything
Before giving the fan away, or to start again: deletes all settings, riders, sensors, the Wi-Fi network, PIN, link keys and the logbook. The fan restarts as new, with its own access point and the default password. Firmware stays.
